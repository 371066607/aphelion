# 远日点 × 环世界全量对齐总计划

> 目标：殖民地里每一个小人（含指挥官）都按环世界那套 **需求 → 工作优先级 → 规划/区域 → 房间质量 → 事件** 自己过日子。  
> 外壳仍是外星迫降家园；星球远征仍是副本。  
> 红线不变：不做文字聊天、不回退 3D、不加重生叙事、资源只在殖民地花。

状态：草案（等人拍板分叉后拆票）  
对照版本：RimWorld 1.4/1.5 核心（不含 Ideology 教义、Royalty 头衔、Biotech 基因、Anomaly 异常；需要再开）

## 3. 建议分叉（先拍板，再拆票）

不拍板也能开 P0。这些会改变后面所有票。

1. **时间**：一天继续 210 秒，还是拉长到 ~8–12 分钟，并加暂停/×2/×3？  
   建议：**加暂停 + ×2/×3，一天先拉到 8 分钟**。不拉长的话，作息表 24 格没有意义。

2. **工单 Bills**：灶台/工坊改成「做到 N 件」还是维持自动产？  
   建议：**要工单**。没有工单就永远不像环世界的生产。

3. **划区**：仓储/种植要不要「地上拉框」而不是只靠建筑？  
   建议：**要**。规划工具已经有拉框，正好复用。

4. **囚犯/奴隶**：要不要？  
   建议：**不做奴隶**（家园伦理）。囚犯关押与释放可放 P3 或永不做。

5. **DLC 深度**：教义、基因、贵族？  
   建议：**永不做**，除非单独开一季。外星设定用法则/标本就够。

## 4. 阶段交付（按「玩起来像」排序）

### P0 — 能看着过日子（1 周量级，优先）

没有这些，后面做得再深也像加速的蚂蚁。

1. **暂停 / 倍速**（空格暂停，`1/2/3` 或 UI 按钮）
2. **警报条**（饿、困、倒地、没粮、袭击、蓝图缺料；点击镜头跳转）
3. **指挥官与居民同一套工作大脑**（现在两条链，会再分叉出 bug）
4. **一天时长与需求消耗对齐**（一天里会饿一顿、夜里想睡、白天能看完砍一棵树）
5. **右键上下文补全**（蓝图=去建造，货架=搬运/过滤，倒地=救援已有）

完成标准：暂停后标树、放蓝图、再放行，能看完「走过去 → 干活 → 吃 → 夜里回舱」。

### P1 — 生活与生产闭环（环世界骨架）

6. **作息表**（每人 24 格：睡/工作/娱乐/任意；默认夜里睡）
7. **念头**（至少 20 条常用：地铺、漂亮屋、吃生食、空娱乐、社交、寒冷）
8. **选中检查器做成需求条**（食/睡/乐 + 即将：美观/舒适）
9. **工单 Bills**（厨房/工坊/篝火：做什么、做几件、完成后停）
10. **仓储划区 + 禁止物品**
11. **种植划区**（拉框田 + 选作物；人去播/收）
12. **房间职能判定**（卧室/食堂/娱乐室/医院/车间）
13. **工作动画**（建、搬、炊、研究至少一个可见循环）

完成标准：不点征召，一个晚上能看到：收工 → 吃饭桌 → 篝火 → 回卧室。

### P2 — 质量、身体、动物、火

14. 美观 / 清洁 / 清扫工作
15. 修理、建筑掉耐久
16. 部位伤与包扎（可简化成 6 部位而不是 20）
17. 尸体、埋葬、悲伤念头
18. 动物个体（牧场拆成几只羊）
19. 火灾与灭火
20. 活动区 Restrict
21. 打猎规划

### P3 — 深度（可裁）

22. 更多崩溃
23. 技能热情 / Incapable
24. 囚犯（非奴隶）
25. 义体、装备磨损
26. 药物（建议仍不做）
