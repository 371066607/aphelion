## 实际操作与观察

1. 从开场画面点击“活下去”进入新档。普通家园显示 3 名居民、0 建筑和默认 128×128 地图。
2. 点选 `小满·三号`，点击“征召”，再点击地面。命令栏显示“移动中”，画面出现虚线路径，居民实际离开原位置。随后解除征召。
3. 按 `G`，从正式建造目录选“舱板地板”，在地图上放置并按 Esc 退出连续放置。界面显示“✔ 舱板地板 建造完成”；再次打开目录时数量为 `1/16000`，木材由 50 降为 49。未启用无限建造。
4. 按 `E` 打开远征编组，只保留 `小满·三号`，选择“未知星球 · 首次着陆时观测”并出发。实际着陆标题为 `APH-P9CDE8818 · 酸蚀巨沼星 (远征)`，队员 1、留守 2。
5. 把视野缩到 64%，在地图上右键给一件可搬运资源下达优先命令。队员走到目标后，界面显示 `+2 晶体矿`，任务进度由 `0/6` 变为 `2/6`，负重由 0 变为 6；异常进度始终为 `0/6`。货物来自本轮实际世界交互，没有注入。资源搜集任务进度与异常信标扫描是两套状态，本轮没有把搬运结果记成异常发现。
6. 直接刷新页面，正常经过开场入口恢复存档。远征条、HUD 和画面恢复为同一个活动远征：标题仍是 `APH-P9CDE8818 · 酸蚀巨沼星 (远征)`，任务进度仍为 `2/6`、负重仍为 6、异常仍为 `0/6`。这一步确认了首次着陆和刷新恢复使用同一持久星球名称/群系标题。
7. 点击“召回队伍”。回到家园后人口为 3、负重为 0，舱板地板仍在，界面提示 `小满·三号 已将物资送入仓储`。
8. 再按 `E`，已知目的地列表出现 `APH-P9CDE8818 · 已观测`。仍只选一名队员并提交；再次着陆的 ID 与群系标题完全相同，新 Active Run 的任务进度为 `0/6`、负重为 0。最后再次召回，安全回到三人家园。
