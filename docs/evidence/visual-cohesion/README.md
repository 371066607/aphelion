# 正式游戏视觉统一：实现与证据

2026-10-04；工作分支 `codex/visual-cohesion`，基线 `4658e35`，对应 #216。

## 已实现

- 独立透明环境图集：两种树、灌木、矿石、残骸、迫降补给、异星植物共 12 项。保留生成原稿及实测边界；按实测矩形等比缩放、底部锚定，失败回退程序绘制。数据经 `assets/build_environment.py` 自动嵌入单文件。
- 地表只读 TerrainModel 的真实格；纹理和非水陆边缘过渡烘入原有 36 块 LRU 缓存。水陆边界保持准确；世界坐标采样避免跨块纹理错位。资源 uid、产出、占格和寻路不变。
- 家园夜幕与暗角减弱；光源来自补给锚点、通电路灯、篝火，移除家园旧玩家手电光圈。远征保持原合成路径。建筑没有透明混合。
- 连续墙保留真实 48px 厚度；侧面阴影仅沿外露边，地板覆盖整格并使用已有材质。实景发现的“地板又画成通用建筑”重复绘制已修复。
- 建造目录分结构/生活/生产/仓储/电力/防御，使用正式素材缩略图；详情调用真实 `Construction.materialNeed/cellsOf`，包含旧矿材成本和居民加成。库存调用 `Colony.stockOf`，显示可用量而非重复累加数字库存。
- 居民头像按 Humanoid 的实际脸型/贴图缓存；重绘保留键盘焦点。原生按钮的 Enter/Space 不再触发世界暂停。家园隐藏远征行，远征隐藏家园物资。普通入口隐藏探针、无限建造按钮并拒绝 F8。

## 画面与交互证据

`rooms-day/dusk/night.jpg`：**自由建造的视觉夹具，不是生存通关证据**。使用正式 `game.html`，seed 58098、三名居民、两间合法空地房间、72 个构件，保留自然资源；三床旋转 0/1/2。`rooms-restored.json` 证明读档后仍有 72 构件、两房间面积 12/16 格、三张床分配、原生存档未改。`before-day/night.jpg` 为先前构建的开局基线，房间图不与它伪装成同一建筑布局。

`catalog-1280/1440/1920.jpg`：实际 1280×720、1440×900、1920×1080 视口。720p 抽屉 bounds 为 x=0..1280、y=284.2..672，无越界。普通无参数入口实际经过开场按钮；家园远征行隐藏、无运行探针、无限建造按钮隐藏、F8 无效；医疗舱显示研究原因且规划按钮禁用。最终普通入口对头像实际按 Space/Enter，选人成功、模拟继续，重绘后焦点仍为同一居民的 BUTTON；见 `keyboard.json`。

## 性能

先前探索性采样因居民需求随真实等待时间变化，不能作为前后结论。目录只纳入 `controlled-*`：每组重建 seed 58098、20 名固定 id/seed 的居民、统一初始需求、2059 个非居民对象；1440×900、DPR 1；正式 requestAnimationFrame 主循环，10 帧预热后采 120 帧；白天/夜晚各三组。计量包含模拟与 Canvas 命令提交 CPU 时间，不代表 GPU 呈现耗时。

| 正式画布 frame CPU p95（ms） | 基线三组 | 新版三组 | 三组 p95 中位数 |
|---|---|---|---|
| 白天 | 5.9 / 5.4 / 5.6 | 4.5 / 5.3 / 5.4 | 5.6 → 5.3 |
| 夜晚 | 6.0 / 6.2 / 5.7 | 6.2 / 5.9 / 6.0 | 6.0 → 6.0 |

本样本符合 16.7ms 和相对增幅 ≤10% 的本轮预算；不据此声称所有机器提速或持续 60fps。HTML 体积约 40.1MiB → 41.7MiB；精确字节见 `summary.json`。冷启动/完整 GPU 内存尚未测量。

构建通过；1081 单元、161 场景、7 Boss、98 UI 测试通过。性能门禁在同时打开浏览器时出现 530/531ms 超过 500ms 的历史同类波动；关闭测试画布后的隔离终检为 483ms，6/6 通过。两次记录均保留，未修改阈值或模拟代码。日志中的 DOM 桩模拟结果与上述真实画布结果分开看待。

- 追加旧版对照：`construction-baseline-300s/600s.json` 在 `4658e35` 上执行相同 seed/72 规划/采集命令，两个窗口均为 17 建成、55 排队。说明旧版也未完成这套施工验收；因居民初始随机状态和点击前已运行约 31 秒与新版不同，不能用数量差异判断性能或断言两边是同一个根因。需要单独定位运输与施工链路。
- 完整天气/火灾/袭击/停电/跨远征的人工画面巡查、75%/150% 缩放与 DPR 2、冷启动解码计时尚未完成。自动场景覆盖不等价于这些人工验收。

## 重现

```bash
python3 build.py
# 可选基线；临时输出不进入仓库
git show 4658e35:game.html > /tmp/aphelion-visual-baseline.html
python3 tests/serve_visual_lab.py --baseline /tmp/aphelion-visual-baseline.html
```

打开 `http://127.0.0.1:8766/tests/visual_lab.html`。专用服务器只在 `/tests/isolated-game.html` 和 `/tests/baseline-game.html` 注入内存 localStorage facade，正式 bundle 不变；直接打开测试端点也有私有内存 fallback。实验台在清档前检查隔离标记，并在报告中比较真实 localStorage 是否保持原值。切换版本/重载整页丢弃实验档；“读档/刷新画布”保留内存档。普通 `/game.html` 不被服务器注入。
