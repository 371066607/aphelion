# 殖民地优先重设计：把模拟变成游戏

> 决策日期：2026-09-07 · 用户拍板「殖民地是游戏本体」
> 前置诊断见本文第 1 节；执行计划见第 3 节。

## 1. 诊断：现在缺的不是系统，是循环

代码体检的结论很不舒服但很明确——**模拟层做得相当完整，游戏层几乎不存在。**

### 1.1 过了第一夜，游戏就不再向玩家要任何东西

`src/opening.js:112`：

```js
function objective(opening, buildings){
  if(opening.nightDone) return null;          // ← 此后永远是 null
  if(!hasHouse(buildings)) return {...'今夜之前：盖一座居住舱'};
  if(!opening.sleptInHouse) return {...'走进居住舱按 [E] 睡'};
  return null;
}
```

盖屋、睡觉，然后——沉默。代码里没有第二个目标。玩家说「玩不下去」，
这就是字面意义上的玩不下去。

### 1.2 什么都丢不掉

- **没有胜利条件**：全项目搜不到任何终局判定。
- **没有殖民地失败条件**：没有任何代码检查居民归零。**殖民地不可能覆灭。**
- **死亡几乎没有代价**：`stats.deaths++` → 存档 → 结算页 → 「新星球」按钮。
  研究点、科技、居民、资源全部保留。死亡是一次场景切换，不是失败。

而威胁阶梯是好的：`config.js:662 wealthPerThreat: 120`，
`events.js wealthScore → threatLevel`。威胁确实随财富上涨——
**但在一个不可能输的游戏里，上涨的威胁只是烟花。**

### 1.3 根因

环世界的循环从来不是「需求 + 工作」，而是一台**压力引擎**：

```
财富 ↑ → 袭击点数 ↑ → 被迫把财富换成韧性(防御/医疗/储备) → 财富 ↑ → …
```

它同样没有胜利条件，却不需要——因为**失败是永久且彻底的**，
赌注替代了终局。本作忠实复刻了模拟层，却漏掉了让它成为循环的两件事：
**永久的赌注**，和**明天还要再来一次的理由**。

去掉失败，整套模拟就退化成一个水族箱。

### 1.4 设定在和循环打架

支柱「殖民地是家、星球是副本、资源只在殖民地花」把殖民地定义成了**中枢**。
中枢按定义是安全的。但你造的每一个系统（念头、心情、崩溃、温度、污秽、美观）
**只有在家会被威胁时才有回报**。

更糟的是两个经济体在争夺承重位：远征供应材料 → 种田/烹饪/搬运沦为装饰；
反过来若殖民地自给自足 → 远征可有可无。**无论哪边赢，另一边都是死重。**
（远征独有物品定义只有约 10 条，其余都是可以自己种/挖的散装资源。）

生存机制也被劈成两种互斥的幻想：

| | 远征 | 殖民地 |
|---|---|---|
| 操控 | 直接、附身 | 间接、导演 |
| 压力 | 氧气倒计时、战斗 | 饱食/精力/心情、季节 |
| 时间尺度 | 分钟 | 天 |

指挥官就是那道裂缝——在外是动作英雄，在家是 1 号居民。
**这就是为什么 `meta.playerNeeds` 里根本没有 `mood` 字段**：他不是真的居民。
那不是 bug，是设计裂缝在代码里露头。

## 2. 决策：殖民地是本体

- 殖民地是**前线**，不是中枢。它可以覆灭。
- 远征降级为**短程补给跑**，只带回**种不出来的东西**（标本/遗物/科技种子），
  **永不产出散装粮食/木材/金属**。
- 指挥官是居民之一（有心情、会永久死亡），不是上帝光标也不是不死主角。
- 给这场戏一个**结局**：修好发射器，离开这颗星球。

红线不变：不做文字聊天、不回退 3D、不做重生叙事、不做奴隶、资源只在殖民地花。
（「造发射器离开」是殖民地超级工程，不是重生叙事，落在红线内。）

## 3. 执行计划（按「让循环成立」排序）

### T1 — 赌注成立（本轮已做）

殖民地覆灭判定 + 指挥官成为真正的居民。
没有这个，后面每一项都还是烟花。

- [x] 居民永久死亡（**已存在**：`main.js:5399` 从名册移除 + 落尸体 + 幸存者悲伤）
- [x] **居民归零 = 本局结束**（此前完全缺失）
- [x] 指挥官有心情，由念头驱动（复用 ADR-31 机制）
- [x] 指挥官之死 = 一次居民之死，不再是「换个星球重来」

### T2 — 游戏要一直向玩家要东西

替换掉第一夜之后就返回 null 的 `objective()`，改成**不会枯竭的目标阶梯**：
活过第一个冬天 → 稳定粮食储备 → 通电 → 立起防线 → 医疗 → 发射器。
每一级都读真实殖民地状态，不写死剧本。

### T3 — 季节（压力发生器）

天气、温度、农业都已具备；缺的是**年的形状**。冬天种不出东西，
「今天该干什么」由此有了永远成立的答案：**囤，否则死**。

### T4 — 远征降级

掉落表改为只出独有物品。散装资源必须自己种/挖。
远征从「刷材料」变成「为了那件东西冒一次险」。

### T5 — 结局

发射器超级工程：耗尽积累的财富，通关离开。
让「攒东西」第一次有了意义。

## 4. 不做

- 不把远征做成环世界世界地图商队（远征保持副本）
- 不做重生/母星/舰队叙事
- 不因为「殖民地会覆灭」就加自动存档回溯（那等于取消赌注）
