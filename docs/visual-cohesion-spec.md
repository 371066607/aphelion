# 家园视觉规格（2026-10-04）

人物沿用 78px 内容高度。环境素材的目标包围盒在 `CFG.visual.environmentSizes`：树约 132×142px，灌木/矿石约 45–50px，补给舱约 86×65px；实际按图集 alpha 实测裁切等比 contain，底部与实体脚点对齐。树冠尺寸不参与采集距离、碰撞或资源 uid；树变体由稳定世界坐标选取。选中人物在树冠下时有前景位置提示，树木不透明淡出。

地面以低饱和草/土为背景，建筑为奶油舱板，设备青绿，生活光源暖黄，危险提示保留红色。地表色板是显示表，TerrainModel 的水域/肥力/可建规则仍为唯一事实源。48px 格和既有建筑朝向不变，墙可见厚度就是占格厚度；门使用既有闭合外观，不伪造尚未存在的开门动画状态。

UI 面板深绿，文字米白，建造目录浅沙色，选中为金/绿高对比边；主按钮和正文约 13px，次要信息约 12px。缩略图使用正式建筑图集/精灵，缺素材用文字占位。静态头像按解析后的 sheet/frame 缓存，加载完成时自然更换缓存键，保留姓名和征召状态。

资产管线：生成原稿 → `prepare_environment.py` 测 alpha 边界并打包 → `build_environment.py` 校验 RGBA/尺寸/矩形并嵌入 → `EnvironmentArt.load/draw` → 实体与迫降点渲染。没有运行时外链、额外依赖安装、API key 或存档字段。

取舍：继续沿用 Canvas 与静态图集，地表只在缓存未命中时烘焙，适合当前约 2000 世界对象。本次增加约 1.6MiB 单文件体积，换来同风格环境；没有证据需要换引擎。将来若真实 GPU/解码成本成为瓶颈，再考虑缩小图集或拆分分发，不为本轮引入新打包器。

验收与已知缺口见 `docs/evidence/visual-cohesion/README.md`。
