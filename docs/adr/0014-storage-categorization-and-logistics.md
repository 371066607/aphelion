# 精细化仓储分类与智能物流系统（Storage Categorization and Smart Logistics）

## 背景
此前，基地内的所有掉落物品均被无差别运送往唯一的固定基准点（`stockpileSpot`：通常是发射台或第一个大仓库门前）。随着食材、熟食、矿料、草药、药包、标本和装备的激增，单一堆点暴露出明显的经营与物流缺陷：
1. **仓储混乱无序**：粮食、矿石和药品混杂在同一个地块，缺乏按需分类机制；
2. **缺乏露天劣化惩罚**：掉落在室外的熟食和药剂永久不坏，玩家缺乏修建封闭库房和收纳货架的现实压力；
3. **搬运效率低下**：居民单次只能抱起 1 个孤立的掉落堆，伐木或挖矿后数十个物品堆产生大量无效折返跑；
4. **缺乏车间就近取料**：厨师做饭、医生拿药和居民就餐必须反复跋涉回大本营取货；
5. **缺少小型室内收纳构件**：2×2 的 `bl_warehouse` 笨重且无法灵活摆放在厨房或病房角落。

## 决策

1. **五大仓储品类过滤与 E 键单键轮转**：
   - 仓储容器（大仓库 `bl_warehouse`、1×1 置物货架 `bl_storage_shelf`）支持五大物资大类过滤：
     - `food`（食材熟食：生肉、野果、熟食菜肴、种荚）
     - `materials`（工业建材：矿石、铁料、石材、木材、合金）
     - `medical`（医疗药品：殖民地药包、草药、精纯试剂）
     - `specimens`（异星标本：各类未化验异星动植物标本）
     - `gear`（特种装备：防寒服、防酸服、外骨骼等）
   - 走近仓储设施时，右上角提示当前允许品类，按 `[E]` 在 5 种高频预设间单键循环切换：
     `[全部允许] → [仅食材熟食] → [仅建材矿料] → [仅医疗药品] → [仅标本装备]`，零弹窗阻断。

2. **露天劣化耐久模型与天气联动（Outdoor Weather Deterioration）**：
   - 地面掉落物具备 `decayHp: 100` 耐久值：
     - 易腐品（生熟食物、草药）：室外基础损耗 **1.5 HP/生产跳**（晴天约 4.5 游戏天损毁）；
     - 药品与装备：室外基础损耗 **0.5 HP/跳**（约 14 游戏天损毁）；
     - 矿料建材：**完全免疫风化（decayImmune）**，永久不坏；
   - **恶劣天气乘子**：雨天/雪天损耗速度 **×2**，酸雨天 **×4**；
   - **室内/货架免疫**：凡位于 T9 封闭房间（室内）或货架/仓库格上的物品，**腐烂速率降为 0（永久免疫）**；
   - 耐久归零时触发消散灰尘粒子并从世界中清除。

3. **1×1 轻量置物货架（`bl_storage_shelf`）**：
   - 占位 1×1（48px 格网），建造成本极低（`wood: 6`），可灵活塞入房间角落；
   - 货架上陈列的物品自动享有防雨防风化避难保护；在货架格内轻量绘制当前收纳物品的微缩图标。

4. **专职搬运工与 48px 范围多堆批量运载**：
   - 在居民工作分配中确立搬运优先级；专职搬运工拥有全殖民地寻物视野（`seekR: 1200px`）；
   - **批量多抱（Bulk Carrying）**：前往拾取首个掉落物时，若周围 48px 范围内存在同样兼容送库的同伴物品堆，顺带拾起相邻的 1~2 堆一并抱入怀中（单次上限 3 堆或 50 件），一趟运抵目的地。

5. **车间与岗位 120px 就近取料联动**：
   - 厨房、工坊、诊所与就餐居民在取料时，优先检索自身 120px 范围内匹配对应品类的专用货架；
   - 就近货架有货时就地取用（0 跑图），无货时才回退至大本营综合大仓库。

## 后果
- 强化了家园基建与室内规划的深度，玩家有充分动力为厨房建粮食架、为诊所建药品架、为仓库建封闭防雨墙；
- 搬运吞吐量提升 2 倍以上，彻底根除地面积压数十堆散碎资源造成的严重跑图内耗；
- 恶劣天气对室外露天粮食带来真实威胁，赋予「暴风雨前抢运粮食」极具代入感的生存紧张感；
- 沿用格层静态物与 `meta.res` 现有架构，保持 100% 存档兼容与代码零魔数。
