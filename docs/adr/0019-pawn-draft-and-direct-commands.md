# 环世界式征召与直接命令系统（Pawn Draft & Direct Commands）

## 背景

ADR-18 落地了 Work Tab（优先级网格）+ 自动采集/搬运 AI，殖民地可以自转。但玩家与居民之间缺少 RimWorld 的另一半核心体验：**点选小人 → 直接下达命令**。RimWorld 玩家的肌肉记忆是：

1. 左键点选殖民者 → 征召（draft），小人停下一切自动行为听你指挥；
2. 右键点地面 → 移动；点树 → 砍树；点掉落物 → 搬运；
3. Esc / 再次点选 → 解除征召，回到自动 AI。

当前游戏居民完全由 AI 驱动，玩家无法微观干预（例：袭击时手动把厨师拉回家、指定某人去砍门口那棵树）。本 ADR 补齐「直接指挥」层，与 Work Tab 形成"宏观优先级 + 微观命令"的完整闭环。

## 决策

### 1. 点选征召（Click-to-Draft）

- 家园场景、非建造模式下，左键点击居民（`CFG.command.pickR`=34px 判定半径）→ 设 `s.selectedRid`，该居民进入**征召态**：`updateResidents` 中其 `e.userOrder` 命令优先于一切自动行为（岗位/采集/搬运/游荡/吃饭），但没有命令时**原地待命**（不游荡不找活）。
- 选中环（青色椭圆，脚底）画在实体层之下的粒子层；有命令时画绿色虚线旗标到目标点。
- 解除征召：Esc（`CANCEL_OR_CLOSE` 新增分支）、右键、面板 ✕ 按钮。解除后清 `userOrder`，自动 AI 下一帧恢复。

### 2. 命令面板（Command Panel）

底部居中浮动条 `#cmdPanel`（非阻断浮层，游戏继续运行）：

- **状态行**：居民名 + 当前命令/岗位；
- **按钮**：⛏ 采集（最近 flora）/ 📦 搬运（最近掉落堆）/ 🛏 休息（最近住宅）/ 🍽 吃饭（最近食物）/ ✕ 解除征召；
- **键盘等价路径**（工程铁律）：Esc 解除；按钮为真实 `<button>` 可 Tab 聚焦 + Enter 触发；
- 「移动」不需要按钮——选中态下左键点地面即移动令。

### 3. 五种命令（e.userOrder 运行态）

| type | 目标 | 到达 | 完成动作 |
|---|---|---|---|
| move | 点击点 (x,y) | `moveArriveR`=8 | 清令，待命 |
| gather | flora 实体引用 | `gatherArriveR`=48 | `workOnFlora` 推进，掉落入库堆 |
| haul | dropped 堆 | `grabR`=18 抓取 → `dumpR`=36 入库 | `collectHome` 入库 |
| sleep | 最近住宅 | `sleepArriveR`=40 | `r.isSleeping=true`（醒来由 needsTick 接管） |
| eat | 最近食物（堆/仓库） | `grabR` | `tryEatHere` 吃一口（饱了也只试一次） |

实现要点：
- 命令块插在 `updateResidents` 居民循环内、**睡眠/击倒/崩溃短路之后**（失能者不接令）、饥饿/岗位 AI 之前；
- 走位复用 `APH.Res.walkAround` + 48px 格网寻路（ADR-13），带病/天气/沙袋减速全乘；
- **袭击豁免**：move 命令在袭击中仍可下达（手动撤离！），其余命令在袭击开始时清除交还逃跑 AI；
- 目标死亡/丢失 → 立即清令回 AI；采到的资源掉落走 `spawnDrop`，搬运走 `collectHome`，与自动链路同一条经济管线。

### 4. 点选即接管，非永久状态

`selectedRid` 与 `userOrder` 都是**运行时实体字段**（不持久化）：存档/读档/进远征重建实体后自然清空，与 RimWorld「draft 不跨存档」一致。选中居民死亡 → 下一帧自动解除。

### 5. 与现有交互的冲突消解

- 现有「左键点地 = 玩家寻路移动」保留：**未选中**时行为不变；
- **选中**时左键点地 = 对居民下移动令（不移动玩家）；
- 建造模式（墙拖拽/点地放置）优先级最高，选中态不影响建造；
- 点居民从「玩家走过去」变为「选中该居民」——招募路径改为走近按 E（原有），语义更 RW。

## 后果

- 玩家获得微观干预能力：袭击时拉人回家、指派临时采集、手动补给——经营深度+1；
- 与 ADR-18 Work Tab 互补：宏观管"平时谁干什么"，微观管"现在立刻干什么"；
- 居民循环增加一个命令分支（每帧一次 dst 判断），性能影响可忽略；
- 全部数值进 `CFG.command`（ADR-10）；命令为运行态字段，存档零迁移（ADR-2 兼容）。
