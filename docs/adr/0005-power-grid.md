# 实体导线电力网：发电机/蓄电池/用电建筑靠导线连网，搭不上线就停机

RimWorld 原教旨的电力：导线是可铺的格子实体，建筑 footprint 与导线相邻/重叠即接入；电网=沿导线 BFS 把发电机、蓄电池、耗电建筑连成一张网。耗电建筑（炮塔/水培农场/医疗舱/科研站/路灯）无电停机，农场减产而非绝收；供不应求时按优先级停机（炮塔/医疗舱优先于路灯），蓄电池提供 60s 兜底（耀斑停机期也靠它）。发电机只做两种：**木柴火力发电机**（烧木材，稳定）与**太阳能板**（白天发电，复用 ADR-6 昼夜）。这是「建筑系统联动起来」的题眼。

**为什么手动铺线而不是自动电网**：曾考虑发电机供电半径+自动画连线（省铺放交互），但「手动接线」是 RimWorld 联动的灵魂，砍掉=联动感砍半。导线与墙共用同一套「B 建造→拖拽连续铺设」交互，边际成本低。

**设备家族（RimWorld 四家族裁剪为二）**：火力+太阳能为二。风力（本作无天气风系统）、地热（无地热点位）——放进来只能是摆设，显式裁剪；若未来加天气系统再回来评估。

**电网未激活兼容**：殖民地零发电机 → 视为电网未激活 → 所有耗电建筑默认通电（老档不崩、新手没压力）；玩家放下第一台发电机后电网才计费。断网/缺电的耗电建筑头顶 ⚡ 浮标（分「未接线」与「缺电」两种状态）。

**后果**：
1. 电力走 `colony.buildings`（导线一格一条 `bl_` 记录）+ 定时 BFS（建造/拆除时增量重建，不每帧跑）；
2. 电网数据结构与「炮塔 offlineT/耀斑停机」语义合并——offlineT 保留为事件停机，缺电停机走新 `powered` 状态，两码事不混写；
3. 老档兼容：零发电机=未激活；有发电机后按现网结算；
4. BFS 为纯函数（格网+发电机/电池/耗电建筑集合 → 供电组件），node 可直测——AD-10 数值/逻辑分离。
