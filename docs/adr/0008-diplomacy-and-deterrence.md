# 势力外交与威慑系统：关系度、纳贡平息、通商协定与破袭威慑

殖民地外的敌对势力（Rivals）此前只有单向蓄积怒气与发动袭击，玩家只能被动挨打或在远征中偶然打掉一座静态基地。决定建立完整的**势力外交与战略威慑系统**：

1. **势力关系度模型（-100 ~ +100）**：
   - `s.rivalStates` 扩展 `relation`（好感度/关系值）与 `pact`（条约状态）。
   - 三级关系度状态机：
     - **宿敌 Hostile**（`< -30`）：正常/加速累积怒气；军力占优时必然备战袭击。
     - **中立 Neutral**（`-30 ~ +40`）：袭击门槛提高（军力要求从 1.3 倍提至 1.6 倍，怒气需求翻倍）。
     - **盟友 Allied**（`> +40`）：绝不主动袭击；家园遇袭时有概率派遣援军或赠送补给。
   - 老档兼容：无 `relation` 字段时按性格兜底初始化（`aggressive: -40, expansionist: -15, trader: +20`）。

2. **外交交互（纯函数，收口于 `APH.Rivals`）**：
   - **纳贡平息 (`sendTribute`)**：消耗殖民地仓库或地上堆资源（矿石 15 或 熟食 5 或 药品 2），提升关系度 (+15~+25)，消减怒气时间 (-6 分钟)，化解即刻备战危机。
   - **通商协定 (`signTradePact`)**：中立及以上消耗 20 矿材签署，游商到访频率提高，社交议价额外享受 10% 优惠。
   - **军事威慑 (`deterRival`)**：当玩家防御力达对手 1.2 倍以上时可展示军容，消耗 5 等离子能量，使该势力陷入「畏缩 (cowed)」，暂时停止军事扩张且 5 分钟内不敢备战。

3. **远征反击与破袭联动**：
   - 远征摧毁远端敌基地（`raidBaseSuccess`）后，该势力受到战略重创：军事实力降低 30%，怒气清零，进入虚弱期，直接提升全图战况值（warScore）。

4. **交互入口与 UI 展现**：
   - 全局快捷键 `O` 打开「势力外交（Diplomacy）」浮层（与 R 居民名册、T 科技树、L 图鉴同级）。
   - 显示势力名、阵营色彩、性格标签、军力对比条、当前关系度徽标与当前态度。
   - 三项外交动作按钮（纳贡、通商、威慑），不满足条件时给出置灰说明。
   - HUD 战况条（warScore）增加交互提示 `[O] 外交`。

**后果**：
- 经营主循环增加了主动外交调控策略，玩家在面对强势袭击时有了「花钱消灾」或「展现威慑」的非战斗解法。
- 远征摧毁敌基地有了真正的战略回响，不再仅仅是撒落几件战利品。
- 所有外交逻辑写成纯函数，数据进 CFG，测试完全覆盖。
