# ADR-35: 远征降级与发射器终局（殖民地优先 T4 / T5）

## 状态
已通过（Accepted） · 2026-09-07

## T4 — 远征只带回「种不出来的东西」

### 上下文

掉落表原本是（写死在 `combat.js`）：

```
it_crystal_ore 40 · it_mineral 34 · it_alloy 20 · it_relic 6
```

`it_mineral` / `it_alloy` 都 `store:'mineral'`——**散装金属**。
于是「刷远征」可以整条绕过殖民地生产链：种田、挖矿、烹饪全变装饰，
连冬天都可以靠出门刷装备度过。两个经济体争承重位，结果是两边都不承重。

更糟的是任务简报还在**主动误导**：缺粮时写「此行目标：补给食物」，
缺矿时写「此行目标：矿材」——把玩家往一条本该不存在的解法上推。

### 决策

1. 掉落表移进 `CFG.expedition.lootTable`（ADR-10：代码零魔数），
   只留**换研究点的独有物**：
   ```
   it_crystal_ore 70 · it_relic 30
   ```
2. 散装粮食/木材/石头/铁/矿材/皮革/草药/药品**一律不进远征掉落表**。
   `CFG.expedition.bulkStores` 列出禁入类别，由测试钉死。
3. 种荚**不进掉落表**——它来自实验室化验标本（`SPECIMEN_ANALYSIS`），
   直接掉种子会绕过整条科研链。标本仍由 `specimenDropsOf` 单独掉。
4. 任务简报改口说实话：缺粮 →「该种田了（远征带不回粮食）」，
   缺矿 →「派人采矿或造采矿机」。

### 保留

- 家园侧的散装产出不受影响：补给舱事件（`ev_droppod`）、袭击者溃退掉落、
  自动采矿机、铁矿石 —— 殖民地**能够**自给自足，所以砍掉远征散装不会锁死。
- 古代遗物箱掉 `it_ancient_blueprint` / `it_ancient_core`，本来就是独有物。
- `settleGoods` 仍然认识 `it_mineral`/`it_alloy`（老档背包里可能还有）。

## T5 — 发射器终局

### 上下文

诊断里最刺眼的一条：**全项目没有任何胜利条件**。
殖民地攒到最后没有出口，攒东西本身就没有意义。

### 决策

一条三级终局，接在目标阶梯末尾（`colonyGoal`）：

| 级 | 目标 |
|---|---|
| `endtech`  | 研发「深空信标阵列」`te_deep_signal`（400 研究点，需深空钻探 + 等离子电网） |
| `endbuild` | 建造「深空发射器」`bl_transmitter`（矿 200 / 铁 180 / 石 120 / 木 80，`max:1`，建造 120s） |
| `endgame`  | 通电后走过去按 E → 呼叫救援，通关 |

- 发射器登记为耗电建筑（`load:35, prio:2`）——**「通电才能起飞」不是一句空话**，
  想走就得先把电网撑起来。

  **数值是被实测纠正过的**：最初拍脑袋写 `load:80, prio:1`。
  夜间只有木柴发电机供电（太阳能白天且看天气），上限 `14W×4 = 56W`；
  炮塔+医疗舱保供占 16W —— 80W 的发射器**夜间根本不可能满足**，
  白天也要把 4 台发电机与 6 块太阳能板全造满才勉强够。
  终局会变成一条死路。改为 35W ≈ 夜间余量（40W）的 87.5%：
  逼你几乎造满发电机，但确实带得动。
  `prio:2` 则保证缺电时**先停发射器**，不许它把炮塔和医疗舱挤停机。

### 可达性（同样是实测出来的）

`te_deep_signal` 最初**漏掉了 `TECH_COLUMNS`**。科技图只从这张表渲染，
不在表里的科技在 UI 中根本不存在 —— 玩家永远买不到，整条终局链形同虚设。
已补「终局」列，并加了一条不变量测试：**每个 `TECHS` 条目都必须出现在某一列**
（旧档别名 `te_weaponry` 显式豁免）。

实测终局链：7 项科技共 1060 研究点（≈27 个信标遗件），
造价 矿200/铁180/石120/木80，建造 120s，`max:1`。
- 通关页讲这一局的故事：存续多少天、几人登船、失去了谁。

### 为什么终局是「离开」而不是「永续经营」

设定是迫降难民。**离开就是这场戏的自然结局**，
且它把「资源只在殖民地花」这条支柱推到极致：
发射器一次性烧掉整局积累。红线（不做重生叙事）不受影响——
这是殖民地超级工程，不是重生。

## 后果

- **T3 必须先于 T4**：只要远征还能刷散装粮食，冬天就可以绕过去。
  先有季节压力，砍掉散装掉落才是「关上后门」而不是单纯削弱。
- 远征从「刷材料」变成「为了那一件东西冒一次险」。
- 一局游戏从开局到通关，目标阶梯全程有话说（实测 9 个节点无一空目标）。
