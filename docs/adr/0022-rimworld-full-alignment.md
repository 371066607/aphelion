# ADR-30: 环世界全量对齐的拍板（时间、工单、划区、囚犯）

## 状态
已通过（Accepted）

## 上下文
`docs/rimworld-full-alignment-plan.md` 列出与 RimWorld 核心的缺口。用户拍板五条分叉（2026-09-06）：1–4 要做，5 不做。

## 决策

1. **时间**：加暂停与 ×1/×2/×3；一天 60 分钟（`DAY_LEN=3600`），需求消耗按一天能饿一顿、夜里想睡来校准。
2. **工单 Bills**：厨房 / 工坊 / 篝火改为「做什么、做几件、做完停」，不再有人就无限产。
3. **划区**：仓储与种植用规划拉框画在地上（复用命令拉框），不只靠建筑。
4. **囚犯**：P3 做关押与释放；**永不做奴隶买卖**。
5. **四大 DLC**（Ideology / Royalty / Biotech / Anomaly）：不做。

## 后果

- P0 必须先交付暂停/倍速，否则作息与工单无法验收。
- 指挥官与居民收成同一套 thinkPawn（后续票），避免第三条 AI。
- 远征保持副本 RTS，不改成世界地图商队。
