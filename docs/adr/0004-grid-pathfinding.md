# 网格寻路：居民/袭击者绕墙找门，墙从此是防线

无寻路时代居民直线走、袭击直线冲——墙挡谁都是摆设。决定引入 48px 格网 A*（ADR-4 的格网本来就是「刷怪/建造吸附/寻路用格」，此决策是兑现它）：墙=不可通行格、闸门=可通行格（己方 0 延迟、袭击者开门有延迟）、无路可走时袭击者转入破墙（RimWorld 工兵行为）。居民/过客/士兵共用一套寻路；玩家仍自由移动，撞墙被推挤（不寻路）。RimWorld 参考——这是「墙要挡住袭击」的前提。

**为什么 A* 而不是伪寻路**：格网 2200/48 ≈ 46×46 ≈ 2116 节点，A* 展开量毫秒级；伪寻路（走直角变通）卡死角 bug 概率高、测试成本反而更大。路径缓存到实体（`e.path/pathI`），只在到达/目标变更时重算，居民数量级（几十）无压力。

**卡死的 RimWorld 级兜底**：路径寻不到时居民/袭击者退化直线走+可选破墙，绝不原地卡死；寻路失败≠游戏卡死，测试断言「必有出路或退化」。

**哪些格子算障碍**：仅 `bl_wall` / `bl_gate` / `bl_siege_camp`（围攻营地）为路径障碍。**既有建筑保持可穿越**（RimWorld 里建筑也挡人，但本项目居民无「绕建筑」需求且改动面过大，属显式简化，见后果 3）。

**替代方案（被否并记录）**：
1. 墙只挡敌人、己方穿墙——RimWorld 原教旨里墙挡所有人，否决；
2. 居民直线走+遇墙直角变通（伪寻路）——卡死角，否决；
3. 袭击者全走门、永不破墙——RimWorld 里工兵/强拆就是破墙（围攻转强攻、声追者），否决。

**后果**：
1. 走位 API 变化：`walkToward` 增网格感知版本（无墙环境退化为原直线，性能与旧行为一致）；
2. 袭击 AI 变化：`chase` 从「直线冲脸」变「沿路径找门」，壁障检测接入战斗；
3. **墙/闸门/导线不入 `entities[]`**（区别于 ADR-3：它们占用 2200/48 格量级，会把 `caps.entitiesHard: 400` 打爆），改由 `colony.buildings` 导出轻量格列表，主渲染循环按同一 Y 排序契约绘制——ADR-3 的「统一实体列表」只覆盖会动/会战斗的世界对象，格上静态物走格层。此为 ADR-3 的显式例外；
4. 存档：墙/闸门是 `colony.buildings` 里的 `bl_` 记录（每格一条，`id`+`x/y`），`||默认值` 兼容老档（老档无墙字段=无墙）；
5. 玩家被墙推挤，不再能穿墙走直线。

**兼容**：老档无墙无闸门 → 格网无障碍 → 寻路退化直线 → 行为与旧版完全一致。攻击型路径只在玩家围了墙之后才启用。
