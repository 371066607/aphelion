# 远征探险纵深与异星古代遗迹系统（Ancient Ruins and Expedition Depth System）

## 背景
此前，星球远征（Expedition）副本主要承担为殖民地提供原材料和生物标本的补给职责。虽然群系（Biomes）提供了丰富的视觉与氛围差异，但远征核心玩法长期停留在「降落、击杀地表有机虫子、采集矿料、原路返航」的重复模式中，探险缺乏惊险感、未知感与高价值目标。
为了强化「经营是主城，远征是副本」的核心循环，需要将远征从单纯的打怪采矿升级为具有地牢解谜与终极科技反哺的深度探险系统。

## 决策

1. **确定性地表古代遗迹生成（Procedural Ancient Ruins）**：
   - 在 T2 与 T3 远征星球必生成、T1 星球概率生成一座由古代石壁与能量闸门密封的遗迹建筑群；
   - 生成位置基于星球种子确定（ADR-5 确定性）；
   - 内部处于密封状态，玩家必须靠近能量闸门按 `[E]` 破译解密，或使用等离子枪连续轰击破门；
   - 踏入遗迹后触发迷雾揭开与镜头微震，唤醒内部机械守卫。

2. **机械族守卫与能量护盾机制（Automaton Sentry & Shield System）**：
   - 引入区别于地表有机异星生物的机械族遗迹守卫；
   - **能量护盾机制**：敌人具备 `shield` 与 `maxShield` 属性，受击先扣减护盾，护盾击破后方可伤及本体 HP；脱战后护盾缓慢回充；
   - 守卫具备脉冲蓄力光束攻击；击毁后掉落高价值机械战利品与「史前高能核心 `it_ancient_core`」。

3. **古代数据终端与学识破译解谜（Ancient Terminal & Lore Hack）**：
   - 遗迹房间内设有可交互的数据终端实体；
   - 玩家走近按 `[E]` 触发破译判定，基于玩家/随行学者（`sk_lore`）学识技能等级与随机掷骰；
   - **破译成功**：可安全解锁隐藏密室宝库，或入侵使遗迹内的自动防御炮台反水攻击机械守卫；
   - **破译失败**：触发声光警报，招引周围额外机械守卫。

4. **远古遗物箱与终极科技反哺（Artifact Vault & Relic Breakthrough）**：
   - 遗迹最深处坐落「远古遗物箱 `ancient_vault`」；
   - 开启必得「古代超空间科技残卷 `it_ancient_blueprint`」与高能核心；
   - 带回殖民地后，在科研站（`bl_lab`）通过化验流水线可尤里卡解锁终极科技（如等离子重炮 `te_heavy_plasma`、纳米治疗站 `te_nano_clinic`）；
   - 神器与核心具备较高的物理负重，考验玩家背包管理与取舍。

5. **死亡惩罚与可复现复仇机制**：
   - 严格恪守 ADR 铁律：在遗迹中阵亡依然触发紧急弹射救援返回家园，图鉴与研究点保留，背包携带的战利品遗留在遗迹现场；
   - 遗迹与掉落物状态保留，允许玩家重整军备重返该星球捡尸复仇。

## 后果
- 彻底盘活了远征副本的战斗与探索体验，使「学识 `sk_lore`」与高阶武器装备获得了直接的用武之地；
- 形成「远征探索古遗迹 → 破译击败机械守卫 → 带回高能核心与蓝图 → 殖民地科技大突破」的高成就感闭环；
- 所有数值配置进 `CFG.ruins`，老档无缝兼容，继续恪守零文字对话与单文件分发铁律。
