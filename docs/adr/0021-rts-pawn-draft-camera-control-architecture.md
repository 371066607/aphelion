# ADR-29: 全局上帝视角、Pawn 自主化与纯征召战备控制架构（RTS Camera, Pawn Autonomy & Tactical Draft Architecture）

## 状态
已通过（Accepted）

## 上下文
在过去的版本中，《远日点》采用了“WASD 动作角色扮演”与“殖民地经营战略”的混合控制模型。这种双轨制在引入工作优先级、仓储物流、微环境与直接命令后，暴露了严重的范式冲突：
1. **控制割裂**：玩家用 WASD 推着指挥官跑，而其他几十个小人却由 AI 控制，导致指挥官游离于殖民地社会分工体系之外（“为什么名册里没有我自己”）；
2. **视野受限**：摄像机强绑定在单个角色身上，无法像传统经营游戏那样自由平移浏览基地布局、外星矿区与袭击动态；
3. **微操尴尬**：战斗与战术必须靠单个角色亲自贴脸对枪，无法调动殖民地防御卫兵形成火力交叉网；
4. **交互不直觉**：需要走到发射台、古代终端、遗迹箱 50px 范围内按键盘 E，与现代 RTS/经营模拟的右键点击派工习惯背道而驰。

## 决策

### 1. 视口摄像机解绑与 WASD 平移（Camera Pan）
- **按键重定向**：`W / A / S / D` 和 `方向键` 全面接管地图摄像机平移（Camera Pan），脱离对单个实体的强制跟随；
- **加速与微调**：按住 `Shift` 加速摄像机平移速度；支持鼠标中键按住平移视口；
- **快速聚焦**：双击小人头像（或按 Home / 空格）摄像机瞬间平滑居中到目标角色。

### 2. 屏幕顶部殖民者头像栏（Colonist Bar）
- 屏幕顶部中央常驻所有居民与指挥官的肖像卡片（发型、名字、健康红条、精神压力提示）；
- **选中与居中**：单击头像选中该小人（底部 Inspector 联动更新）；双击居中镜头；
- **征召状态反馈**：被征召战备的小人头像下方显示战备武器图标与高亮描边。

### 3. 指挥官全面 Pawn 自主化（Commander as Pawn #1）
- 指挥官作为殖民地的第 1 号公民（`meta.residents[0]`），彻底融入社会生态：
  - **日常自治**：根据【工作 Work】优先级自主安排作息（伐木、挖矿、科研、建造）；
  - **生理与社交**：饿了去食堂坐下用餐，困了回卧室入睡，偶遇居民停步聊天产生羁绊，受极端气温影响；
  - **脱战自治**：平时不听从直接脚程推搡，全凭优先级自转；
  - **唯一微操入口**：仅当被【征召】或收到右键强制指令时，才放下日常活动听候玩家指挥。

### 4. 纯战备征召与多选编队（Tactical Draft & Box Selection）
- **征召快捷键**：键盘 `R` 键正式重定向为【征召/解散战备（Toggle Draft）】；
- **多选编队（Box-select Squad）**：在地图空白处按住鼠标左键拉框，批量选中多个小人（或 Shift 点击多选）；
- **集结战备**：按 `R` 全队拔枪立正进入战备；
- **战术走位**：右键点击地面，小人以散兵线跑步前往集结点，站在沙袋/墙体后自动获得掩体躲避加成；
- **自动开火与集火**：射程内出现敌对目标且无视线遮挡时，小人自动拔枪射击；右键点击具体敌人强制集火目标。

### 5. 通用右键上下文交互（Universal Right-Click Actions）
彻底废除老旧的“贴脸按 E 交互”，所有大世界行为统一由鼠标右键驱动：
- 选中小人 → **右键点击发射台**：执行「登机出航 / 登机返航」；
- 选中小人 → **右键点击远古遗物箱**：执行「开启遗物箱」；
- 选中小人 → **右键点击古代数据终端**：学识小人前往「破译终端」；
- 选中小人 → **右键点击昏迷击倒队友**：执行「送医抢救搬运到医疗舱」；
- 选中小人 → **右键点击食物/床铺**：执行「优先进食 / 优先休息」；
- 选中小人 → **右键点击被规划标记的树木/矿石/物资**：执行「优先开采 / 优先搬运」。

### 6. 星球远征副本双端统一（Unified RTS Expeditions）
- 远征场景（`expedition`）完全继承同一套 RTS 框架：
  - 返回舱着陆后，探险小队走下飞船，默认处于战备征召状态；
  - 玩家利用镜头平移观察外星地貌与古代遗迹，鼠标右键指挥小队探路、破门、集火机械族哨兵、破译终端解谜、开箱搜刮；
  - 探险完毕全员右键点击返回舱登机撤离。

## 后果
- 《远日点》彻底完成向纯血统环世界（RimWorld）与硬核沙盒 RTS 的脱胎换骨；
- 彻底消灭单人动作跑腿与上帝视角经营之间的系统割裂与代码冗余；
- 玩家获得空前自由的战术指挥权：集结部队、拉设防线、掩体交火、远程空降远征；
- 指挥官作为首要公民完全融入生活网络，生存感与代入感达到极致；
- 保持老存档零迁移损耗（`meta.residents[0]` 承接指挥官数据）。
