# ADR-47: 人型只有一种对象，阵营是字段

已通过（Accepted）· 2026-09-12

人型袭击者是另一阵营的小人，不是另一种生物。环世界里殖民者、过客、袭击者、俘虏都是同一个 Pawn，差别在 `faction` 和谁给工作，不在少一套需求或念头。

## 拍板

> 敌人也是一个完整的人，也会有这些念头。他们只不过是不同阵营的人而已，其它该有的都有。

## 没采用的

- **袭击者卸掉需求/念头，只留战斗壳。** 百人规模看起来省，招降必须重建对象，检查器也看不到「这个人在怕什么」。溃逃变成血量阈值，不是可理解的因果。
- **顶层 80 个可选字段运行时 delete。** 系统会变成满屏 `if (e.mood)`。加减以整块身份/阵营为准，不要散键。
- **再开 `humans[]`。** 违反 ADR-3。人型仍进 `entities[]`。

## 决策

**人型只有一种对象。阵营是字段，不是类型。**

| 有的 | 没有的 |
|---|---|
| 身体、需求、念头、健康、技能 | 按敌我分两套人 |
| `faction`：玩家殖民地 / 敌对殖民地 / 中立过客 | 人型 `enemy` + `isSoldier` |
| 身份：自由 / 俘虏（不做奴隶，ADR-30） | 俘虏时 `new` 一份居民 |
| 工作表和征召：仅玩家阵营 | 袭击者过工单/建造岗 |
| 敌对：袭击 AI（冲锋、破墙、抢粮、溃逃） | 血量魔法代替念头 |

招降 = 同一对象改 `faction`。俘虏 = 同一对象改身份。对象不重建。

非人敌人（噬光群囊一类基因体、野兽）不是小人，仍走 `enemy` / `animal`。人型袭击才收进这套。

性能：人人跑需求与念头，长线需求降频（环世界 TickRare/TickLong 的意思），不要给人型袭击者另做一种数据。20 居民仍是过日子验收；百人袭击是同一套小人 + 降频，不是第二种生物。

## 与已有 ADR

- 延伸 ADR-45：没有主角之后，场上所有人都是小人；敌对也是。
- 遵守 ADR-3：不新增平行人数组。
- 俘虏与释放已有、不做奴隶：ADR-30 第 4 条。本决策让俘虏继续是同一个小人。
- ADR-9：不重命名已有 `rs_` / `fx_` / `rv_` 前缀。实施时人型合并为单一实体 `type`（一次选定，建议 `pawn`），旧档人型 `enemy` 在下一场袭击自然清掉，不靠改全局常量迁移。

本文件是目标契约，不是完成声明。当前代码仍把袭击者写成战斗壳。
