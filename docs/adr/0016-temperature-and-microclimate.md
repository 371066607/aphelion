# 微环境温度热传导与冷热生存控制系统（Micro-Climate Temperature and Thermal Survival System）

## 背景
此前，游戏虽然引入了 11 种天气马尔可夫状态机（含寒潮、热浪、暴雪），也确立了 T9 封闭房间（`Nav.roomsOf`）、实体导线电力网（ADR-14）与食物露天变质（ADR-23），但在物理环境层面缺少温度模拟：
1. **室内外没有温差**：寒潮来袭时躲进屋内依然只能靠穿防寒服硬抗，房间只有挡雨功能，缺乏“避难所暖房”的沉浸感；
2. **缺乏冷冻冷库机制**：在 Spec #133 落地了食物露天腐烂后，玩家迫切需要像环世界一样建造「冷冻库」实现生肉与粮食的永久保鲜；
3. **电力缺乏高价值持续负荷**：除了炮塔和医疗舱外，电网缺乏大宗民用耗电场景；
4. **农田与作物无视季节**：零下几十度室外依然能正常生长，缺乏建造室内温室暖棚的动力。

## 决策

1. **确定性环境气温与房间热阻传导模型**：
   - **室外基准气温**：由当前天气状态与昼夜节律纯函数推导：
     - 晴朗白天 22°C / 夜间 10°C；雨天 15°C / 大雨 12°C；雪天 -5°C / 暴雪 -15°C；寒潮 -25°C；热浪 42°C；
   - **房间热阻传导**：每个 T9 封闭房间具有独立室内温度 `room.temp`；未接入温控设施时，每 30 秒生产跳以 15% 传导率缓慢趋向室外气温；墙体破损缺口时隔热失效。

2. **实体电网温控电器建筑（Climate Control Appliances）**：
   - **电暖器（`bl_heater`）**：占位 1×1（48px 格网），建造成本 `iron: 15, wood: 5`，耗电 40W；当房间温度低于 21°C 且通电时全功率工作，将室内升温至 21°C；
   - **制冷空调（`bl_cooler`）**：占位 1×1，建造成本 `iron: 20, alloy: 3`，耗电 50W；支持 E 键切换目标温度（[避暑 20°C] / [冷冻 -5°C]）；
   - 停电或电网供不应求时自动停机，温度逐渐被室外气温同化。

3. **冷冻冷库食物永久保鲜闭环（Freezer Preservation）**：
   - 与 ADR-23 仓储物流系统深度缝合：
   - 当封闭房间温度 **低于 0°C（冷冻状态）** 时，存放在该房间内地表或货架上的生肉、熟食与草药，**腐烂速率直接降为 0（永久保鲜，永不腐坏）**；
   - 温度在 0°C ~ 10°C（冷藏状态）时，腐烂损耗速度降低 70%；
   - 停电回暖后腐烂速率恢复。

4. **失温（Hypothermia）与中暑（Heatstroke）生理机制**：
   - 人形基础舒适温区为 **10°C ~ 35°C**；
   - 处于过冷环境时每跳累积失温值，处于过热环境累积中暑值（0~100%）；
   - **防护装备**：穿着极地防寒羽绒（`it_suit_cryo`）将耐寒下限拓展至 **-35°C**；穿着防酸/隔热服提升耐热上限；
   - **生理惩罚**：严重度 >40% 移动减速 30%，>70% 心情减益（-8），达到 100% 虚脱击倒（`downed`）；
   - 进入舒适房间或靠近篝火（`bl_campfire`）快速回温消退。

5. **温室暖棚与作物冻害机制**：
   - 作物与种植圃适宜生长温度为 10°C ~ 35°C；
   - 气温 < 0°C 时生长彻底冻结；室外寒潮持续暴露无暖棚保护时，作物缓慢枯萎受损；促使玩家修建室内带暖气的温室大棚。

## 后果
- 极大地激活了基地建设的规划深度：玩家必须为漫长极寒建造带暖气的卧室，为粮食储备建造带空调的密封冷库，为过冬食物建造室内温室；
- 与天气（ADR-15）、电网（ADR-14）、房间（ADR-13）、仓储腐烂（ADR-23）和生存机能（ADR-3）形成五位一体的严密物理世界闭环；
- 所有温控数值全部放入 `CFG.temperature`，保证代码零魔数与纯函数高可测性。
