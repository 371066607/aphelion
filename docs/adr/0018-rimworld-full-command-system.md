# 环世界式全自动命令体系（RimWorld-Style Full Command System）

## 背景
殖民地的经营自 Issue #22 落地了自然资源生态（树木/矿脉/灌木）与 `workOnFlora` 采集逻辑，Issue #81 落地了烹饪流水线，ADR-23 落地了精细仓储物流与智能搬运。然而整个命令体系存在关键的自动化断层：
1. **居民不会自动采集**——砍树/挖矿/采浆果只有玩家手动按 E，居民永远当看客；
2. **搬运工不在优先级网格**——已有的自动搬运是硬编码行为，无法通过 R 面板控制谁搬谁不搬；
3. **烹饪产出不进货架**——厨师做完的菜肴掉在地上，没有自动放入最近食材货架；
4. **自然资源不再生**——砍完一棵少一棵，长期经营必然资源枯竭。

RimWorld 的核心体验是：玩家通过 Work Tab 勾选优先级 → 居民自动执行（采集/搬运/烹饪）→ 资源自动入库 → 殖民地自转。我们要补齐这个闭环。

## 决策

### 1. 优先级网格扩展（Work Tab Extension）

现有 6 列（建造/种植/畜牧/手工/学识/社交）追加 2 个虚拟岗位列：

- **采集 (gather)**：基于 `sk_farm` 技能。未被建筑岗位占用的居民按采集优先级自动走向最近未死亡自然实体进行采集。
- **搬运 (haul)**：基于 `sk_build` 技能（通用劳动）。控制该居民是否参与搬运地上物入库。

虚拟岗位不绑定建筑（无 SLOTS 上限），由优先级值决定是否执行。优先级 0 = 禁止。

### 2. 居民自动采集 AI（Auto-Gather AI）

当居民 `assignByPriority` 返回 `null`（无建筑岗位）且采集优先级 > 0 时，进入采集模式：

- **目标搜索**：800px 半径内最近的未死亡自然实体（`type === T.FLORA && !dead`）；
- **类型优先**：树（木材紧缺）→ 石块 → 铁矿 → 浆果丛/草药丛；
- **走位**：`walkAround` 寻路到目标旁（48px 内视为到达）；
- **采集推进**：调用已有 `workOnFlora(target, resident, dt)` 每帧推进，头顶显示斧头/镐图标 + 进度弧；
- **完成**：资源掉地上 → 居民自动搜索下一个目标；
- **退出条件**：无可用目标 / 袭家警报 / 精神崩溃 / 被分配到建筑岗位。

### 3. 自然资源定时再生（Flora Respawn）

被采集完的自然实体从世界清除后，经过 `CFG.gathering.regenTicks`（树 8 跳≈4 分钟、矿 12 跳、灌木 6 跳）后在原死亡位置 ±200px 范围内随机点重新生成同类型实体。由 `tickProduction` 的大时钟驱动。

### 4. 搬运工列入优先级网格

将已有的自动搬运行为接入优先级网格：
- 采集列值 > 0 的居民，在无建筑岗位时**先执行采集，采集完顺手搬运**；
- 采集列值 = 0 且搬运优先级 > 0 的居民，**只搬运不采集**；
- 两者都为 0 = 纯闲逛/社交。

实际实现：在 `updateResidents` 中，当前已有 `!e.job` 时自动搬运的分支，改为先检查采集优先级 > 0 → 尝试采集（找目标/走向目标/推进采集）；采集无目标时才走搬运分支。

### 5. 烹饪产出入货架

厨师在厨房/篝火完成烹饪后，产出不再只掉在地上：
- 优先搜索 120px 内允许存放「食材」的货架/仓库（复用 ADR-23 `findNearbySourcedItem`）；
- 有匹配货架 → 直接创建掉落物在货架格上（自动受室内保护免疫腐烂）；
- 无匹配货架 → 回退掉在地上（现有行为）。

## 后果
- 殖民地实现完全自给自足：玩家招募居民 → R 面板勾选采集优先级 → 木材/石料/铁矿/浆果源源不断自动入库；
- R 面板网格从 6 列扩展为 8 列（+采集+搬运），操作体验与 RimWorld Work Tab 对齐；
- 烹饪产出自动入库与 ADR-23 仓储形成完美闭环；
- 自然资源可持续再生，长期经营不再断供；
- 所有数值进 `CFG.gathering`（ADR-10）。
