# 居民人际网络与动态社交系统（Resident Social Network and Dynamic Relationship System）

## 背景
此前，游戏在 `meta.bonds` 中保存了一个初始化的平铺字典（`aId|bId: 50`），并在生产跳的同岗共事和极端斗殴（`lowestBondMate`）中进行了基础判定。然而，这一人际关系系统存在严重的浅层孤立与缺乏反馈问题：
1. **缺乏离散状态机**：好感度仅是 0~100 的连续数值，玩家和居民无法得知彼此确切的关系身份（是朋友、死敌还是伴侣）；
2. **缺乏场上可见性（Loss of Embodiment）**：居民在院子里的社交完全处于暗箱状态，没有面对面眼神交流、没有气泡反应，宛如没有灵魂的巡逻机器；
3. **缺乏经营与空间机制联动**：人际好感没有真正撬动生产排班、房间分配和战力表现；
4. **精神崩溃不可挽救**：居民陷入悲伤游荡、绝食或暴躁打架时，玩家只能干等 30~60 秒自然结束，高社交（`sk_social`）属性沦为纯贸易议价挂件；
5. **玩家被排斥在社交网之外**：玩家与居民没有专属的羁绊沉淀。

## 决策

1. **五级关系状态机与纯函数投影**：
   - 好感度以归一化无序键 `idA|idB`（小 ID 在前）保存在 `meta.bonds`，范围 0~100，基准值 50；
   - 提供纯函数 `APH.Res.relationshipTierOf(bondValue)`，离散投影为 5 大阶段：
     - `rival` (宿怨/死敌): `[0, 20)`，图标 ⚡，色彩 `#ff6b6b`
     - `disliked` (不和): `[20, 40)`，图标 ，色彩 `#ffa07a`
     - `neutral` (同僚/平淡): `[40, 60)`，图标 ，色彩 `#dcdcdc`
     - `friend` (朋友): `[60, 80)`，图标 ，色彩 `#8fd4ff`
     - `close_friend` (挚友/伴侣): `[80, 100]`，图标 ❤️，色彩 `#ff85c0`

2. **场上偶遇停步与动森式 Emoji 微气泡**：
   - 居民在日常走位、就餐或游荡中相遇（相距 < 40px）时，检测偶遇社交触发；
   - **动线安全与长冷却**：同一对居民之间偶遇冷却为 90 秒；紧急状态（袭击防务、送医急救、极度饥饿寻粮、睡眠、倒地、精神崩溃）绝对豁免停步；
   - **表现形式**：停步 1.5 秒转向面对对方，头顶浮现 16px 符号微气泡（😊、❤️、💢、💬 等），屏幕弹出轻量浮动动作文本（如「聊了聊天气」「吐槽了伙食」「拌了句嘴」），坚决杜绝开启阻断操作的聊天对话框（恪守零文字聊天玩法红线）。

3. **人际网络对经营与战斗的三维杠杆**：
   - **岗位协同 (Work Synergy)**：好友在同一座建筑上班（如共同采矿、烹饪或研发），获得 `CFG.social.friendSynergy: 1.15` 生产效率加成；死敌同岗则效率打折（0.85），且生产跳有概率爆发口角争执；
   - **同室避嫌 (Room Friction)**：死敌如果被分配睡在同一封闭房间（T9 `roomsOf` 判定），睡眠时获得 `CFG.social.roomRivalMoodPenalty: -5` 心情减益；
   - **战友激励 (Combat Comradery)**：袭击时 120px 范围内有好友并肩作战，提供微弱士气移速加成；若目击好友倒地（`downed`），即刻触发悲痛心情减益（-10 心情）。

4. **精神崩溃人际安抚干预 (Mental Break Intervention)**：
   - 当居民处于悲伤游荡、绝食或砸东西等崩溃状态时，玩家靠近右上角显示 `[E] 安抚情绪`，或由高社交好友路过自动尝试劝慰；
   - **安抚成功率公式**：`Base(40%) + sk_social * 6% + (bond - 50) * 0.5%`（钳制在 15%~90%）；
   - **成功结果**：提前平息崩溃，计时器清零，双方好感 +6，获得「得到开导」心情增益（+10，持续 120s）；
   - **失败与反噬**：轻度崩溃劝解无果（冷却 30s）；若在暴躁打架（`brawl`）或砸东西（`tantrum`）期间安抚失败，崩溃者被激怒当场转火攻击安抚者，造成轻伤并扣减好感。

5. **玩家入网与上下文交互按键**：
   - 玩家作为社交节点之一，键名为 `player|rs_id`；
   - 玩家走近正常居民：按 `[E]` 打招呼（+2 好感，冷却 60s），按 `[F]` 款待请客（消耗 2 粮，+20 印象与好感）；
   - 玩家走近崩溃居民：`[E]` 语义自动切换为安抚劝解。

6. **名册面板集成**：
   - 在 `APH.UI` 的居民名册（`roster`）卡片中直接渲染人际关系徽标与关键羁绊（挚友/死敌），直观反映其社交健康状况。

## 后果
- 殖民地从单一的生产工具人升级为具备动态社交温度的活人社区；
- 人际关系深度反哺排班、住宿规划和危机处置，赋予 `sk_social` 技能关键战略地位；
- 沿用 `meta.bonds` 原生数据结构与 `APH.Input` / `APH.UI` 现有接缝，保持零破坏性与老档无缝兼容。
