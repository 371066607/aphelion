# ADR-45: 没有主角

## 状态
已通过（Accepted） · 2026-09-07 · **取代已撤回的 ADR-44**

## 用户拍板

> 只要有任何一个人活着都能继续，另外没有主角，都是角色，没有指挥官，要参考环世界

---

## 我先做错了一版

ADR-44 我做的是**继任**：指挥官倒下、最资深的殖民者接手、本局继续。
跑通了，也过了实机验证 —— 但方向是错的：它还在保主角。

我在 ADR-44 里写过一句话，正是走错的原因：

> 未采用「镜头脱离指挥官」方案 —— 那会砍掉所有 `[E]` 交互。

**这个论证站不住**：环世界里根本没有 `[E]` 交互。睡觉、吃饭、砍树、搬运
不是玩家走过去按键，是**下令让殖民者去做**。而这套指挥层
（选人 / `orderMove` / `orderGather` / `orderHaul` / `orderSleep` / `orderEat` /
工作优先级表 / 征召 / 划区 / 规划标记）**这个项目早就全有了**。

指挥官不是长在指挥层旁边的东西，他是长在它**上面**的一层多余物。
我把「现有交互挂在主角身上」当成了约束，其实它就是待拆的东西本身。

---

## 决策

**玩家没有化身。所有人都是殖民者。只要还有一个人活着，本局就继续。**

### 换上的

- **开局班底 3 人**（`CFG.colony.startingColonists`）。
  没有主角之后，零居民 = 什么都不会发生 —— 没人干活、没人接受命令，
  连「殖民地覆灭」都无从判起。只在全新存档播种，老档零迁移。
- **HUD 报殖民地**：人口 / 床位，取代六条个人状态条。
- **检查器默认给殖民地概览**（人口·研究·下一个目标·「点选一个殖民者下达命令」），
  取代原先的「⭐ 指挥官(你)」。
- **暴露读数换主体**：从「主角的暴露」变成「暴露最严重的那位殖民者」——
  这个指标对殖民地仍有意义，只是主语换了。
- **远征 = 派队**：优先派已征召的殖民者，一个都没征召就全员出动。
  他们是普通的 `RESIDENT` 实体，选中/下令/征召那套原样适用 ——
  不需要为远征另造一套操控。

### 终局差点被我删没

T5 的胜利出口原先是「走到发射器旁按 `[E]` 呼叫救援」。
拆掉 `[E]` 之后**整个游戏失去了唯一的胜利出口**，而且不会有任何报错。

现在它是发射器自己的一个命令（`callRescue`，在建筑检查器里）：
通电给按钮，没电说明原因。用例钉死了两种状态。

**拆一个交互层最危险的地方，不是拆坏了什么，是拆掉了某件只有一条路能到的事。**

## 还没做完（已进 BACKLOG）

拆掉 `[E]` 之后，有几件事暂时**没有入口**了，需要各自变成殖民者命令或面板动作：

- 招募过客 / 请客（原 `[E]`/`[F]`）
- 安抚崩溃的殖民者（提示已经在说「派人去安抚」，但还没有这条命令）
- 远古遗物箱 / 数据终端 / 能量闸门（远征 `[E]`）
- 切菜谱 / 切配方 / 切化验目标（部分已在建筑检查器里）

另外 `s.px/s.py` 还作为残留字段存在（少数地方当「镜头焦点」用），应当彻底清掉。
