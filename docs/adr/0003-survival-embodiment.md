# 场上体现：俯卧一张、饿病靠行为，不另画需求走循环

生存状态要在院子里从身体认出来，但环世界用同一具身体放平，饿是去吃饭，病是走慢或躺床。我们曾考虑为睡/倒/病/觅食各做走或 idle sheet，否决：配额会炸，且和「参考环世界」冲突。决定：只新画俯卧 idle（现有 16 帧四向格子）；睡着与击倒共用，击倒叠伤痕不换色不叠五官。觅食走去吃饭，病走慢、重则躺医疗床。玩家在家园永远相当于征召：不自动睡、不自动找食，床边 E 才睡，精力见底会累塌。

**2026-08-29 · #60 修订**：俯卧仍只有这一种姿势语义，但允许整人身份逐张补齐预烘焙 sheet。首张为脸 0 无包居民 `hum_0_nopack_prone`；未配身份或专用图未就绪时用 `player_prone` 通用回退。渲染时不旋转 walk、不换身子颜色，也不往头上叠五官。

**2026-08-29 · #64 修订**：病情严格超过 20 时，家园居民（含崩溃游荡路径）与玩家的普通走/跑速度统一乘 0.6；远征冻结家园需求，因此玩家速度不变。病号 `✚` 的显示阈值独立配置为病情达到 20，仍不新增病态 walk sheet。
