# 人形 sprite：32 走 + 16 idle，两张 sheet，等高

家园里玩家走循环按 32 帧横排（下/左/右/上各 8）；DESIGN ADR-11 已于 2026-08-28 从 2×4 改到此布局，走循环配准改脚底（抬腿会把质心拽高）。过客/居民还是程序化小人，体量和画风对不上。决定：人形（玩家、居民、过客、士兵）同一身高；走循环每向 8 帧、idle 每向 4 帧、walk/idle 分两张 sheet；生图仍走 Codex。过客/居民用 4 个整人 identity，有包/无包两套，不叠五官。第一刀不做运行时换色。

选两张 sheet 而不是一张长条：走坏了不必重画呼吸。选整人出图而不是叠脸：走循环配准过不了「身份不漂」。
