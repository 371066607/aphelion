# ADR-20: 环世界式底栏标签、检查器与规划划区系统（RimWorld Bottom Tabs, Inspector & Designation System）

## 状态
已通过（Accepted）

## 上下文
在 ADR-18（工作优先级表）与 ADR-19（小人征召）之后，游戏依然缺少环世界最标志性的“全景沙盒指挥感”：
1. **界面入口分散**：屏幕左侧悬浮着独立的建造大圆钮和名册小圆钮，右上角有外交快捷键，缺少统一的全局导航条；
2. **缺少检查器（Inspector）**：玩家点击任何小人、建筑、植物、地面时，没有信息卡片告知属性与状态，玩家自己的角色（指挥官）在世界中缺乏身份展示；
3. **缺少规划划区（Designations）**：小人采集要么是自动找全图野树（会误砍绿化），要么只能手动一个个按 E 或单独征召，无法像环世界那样拉框圈定一批树木/矿石一并砍伐开采；
4. **缺少右键微操（Right-click Prioritize）**：无法选中小人右键指定“优先开采此目标”。

## 决策

### 1. 底部常驻主标签栏（Bottom Main Tabs Bar）
在屏幕底部中央常驻环世界标准主标签栏（全中文、紧凑半透明深色）：
- **【📋 命令】**：展开规划工具抽屉（砍伐、开采、搬运、拆除、取消）；
- **【🔨 建筑】**：展开建造抽屉（原 `buildRow`），并正式移除左侧悬浮的 `#buildBtn`；
- **【👥 工作】**：打开居民名册与优先级网格（原 `roster`），正式移除左侧 `#rosterBtn`；
- **【🔬 研究】**：打开全屏科技树（原 `techMap`）；
- **【🌐 外交】**：打开势力外交面板（原 `diplomacy`）。

### 2. 左下角通用检查器（Bottom-Left Inspector）
屏幕左下角常驻半透明信息卡片，根据当前左键选中的实体动态渲染：
- **指挥官（玩家）**：显示头像、名称「⭐ 指挥官(你)」、生命/饱食/精力/氧气数值条、当前武器/装备、当前行为状态；
- **居民（Pawn）**：显示头像、名字、性格、岗位、心情/饱食/精力数值条、当前具体行为（“正在前往伐木”、“待命中”）；
- **自然实体 / 建筑 / 掉落堆**：显示名称、耐久（HP）或数量、当前规划标记状态；
- **地面 / 地形**：显示地貌类型、室温（°C）、房间类型（卧室/工坊/室外）。
- 点击空白区域：自动折叠或显示地形简报；Esc 键可清空选中。

### 3. 规划工具箱与鼠标拉框圈选（Designation Tools & Drag Selection）
点击【📋 命令】展开工具抽屉：
- **🪓 砍伐（Chop）**：标记树木、灌木；
- **⛏ 开采（Mine）**：标记石块、铁矿；
- **✋ 搬运（Haul）**：标记地面掉落堆；
- **🔨 拆除（Deconstruct）**：标记玩家建筑；
- **✕ 取消（Cancel）**：清除选框内所有实体的规划标记。

交互手感：
- **单点**：鼠标点击单个实体，加上或取消标记；
- **拉框（Box Drag）**：在地图上按住左键拖拽，绘制青色半透明虚线框（`rgba(89,217,255, 0.15)`），松手时框内所有匹配实体一并打上标记；
- **视觉标记（Badges）**：被标记的实体头顶悬浮对应白色图标（🪓 / ⛏ / ✋ / 🔨），带轻微呼吸光效。

### 4. 严格规划驱动的派工闭环（Designation-Driven Work AI）
- **无标不采（Strict Designation）**：居民不再盲目全图乱砍乱挖，**仅**当自然实体具有有效 `designation` 时，设置了采集优先级（`sk_gather > 0`）且无建筑岗位的居民才会主动前往；
- **自动清标**：目标实体死亡、耗尽或入库后，标记自动消除并从队列移除；
- **指挥官联动**：玩家空闲且站立在被标记实体旁时，同样会自动执行开采（与手动 E 同效）。

### 5. 右键强制优先执行与取消（Right-click Prioritize & Dismiss）
- 选中小人（或指挥官）时，在被标记的实体上点击**右键**，立即为该角色下达最高优先级 `userOrder`：“优先开采 / 优先搬运”，无视普通排队；
- 空白处右键：退出当前命令工具 / 清空选中。

## 后果
- 玩家获得完整的环世界核心交互体验：底栏切标签、拉框标任务、左下角查属性、右键下微操；
- 彻底解决“指挥官自己没有角色卡”的痛点，指挥官作为首要 Pawn 完整呈现在 Inspector 中；
- 移除左侧分散的悬浮按钮，UI 布局全面收敛整洁；
- 遵循 ADR-10（零魔数，配置全进 `CFG.command`）与 ADR-13（寻路与网格层兼容）。
