# 开场起源：末舰迫降、开场短片、第一夜当前目标

进门后不知道自己是谁、下一步干什么。决定：不拆「殖民地优先」（仍永远出生在这片院子），把院子改口为末舰新曙光的迫降点；进院子前播五张全屏静帧开场短片；进院子后同一时间只给一条当前目标（盖居住舱 → 进去睡），睡醒后不再指挥。过客开局不刷，房子完工后才允许来，入睡后才走进来。

**为什么只改口吻、不改出生结构**：拆成废墟开局会让第一分钟更空，和「活下去」相反。远征仍是发射台补给，不进短片、这轮不改循环。

**为什么是静帧不是真电影 / 2.5D 过场**：没有过场系统，红线不回退 3D，体积已经很大。五件事用五张动森风插画讲完。新档约 30 秒可跳到第五镜；有存档不播；死亡不重播。

**后果**：
1. 舰名新曙光沿用为家园名；标题卡不再写「这是你的家 / 回到家园」，第五镜按钮是「活下去」。
2. 新模块 `APH.Opening`：开场短片时钟与第一夜（当前目标 + 第一个过客闸门）两条纯函数缝，存档 `||默认值`（ADR-2）。
3. `meta.tut` 轮播键位不再当开局引导。
