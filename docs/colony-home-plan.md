# 从末舰残骸，到异星家园

2026-09-12 用户确认方案。首个完整对外版本必须覆盖五阶段，普通 `game.html` 入口进入；双房间原型保留回归。本文件是交付清单，不是完成声明。

没有主角，三位普通幸存者起步；家园永久保留，远征是需求驱动的副本。温暖手绘，奶油舱板、青绿旧设备、土色地面和暖灯。LLM只可丰富文案，无API可完整游玩。资源只在家园花费。性能验收20居民。

## 五阶段

1. 契约与兼容：修订地图、几何、库存、仿真和扎根ADR，迁移样本保证旧布局、物资、已付蓝图和旧居住舱床位保留。
2. 正式建造与物流：共享BuildGrid；墙门连通；床1×2、桌2×2、工位2×1，四向旋转的预览/碰撞/绘制/互动一致；基础墙门床地板仓储烹饪开局可用。采集→搬运→运料施工→入住；工单预订/到场工作，取消倒地堵路释放认领，物资不吞不复制。
3. 大地图与生态：128×128格；迫降旷地、林地、湖岸沃土、岩丘矿脉、异星植物丛、残骸带。保底三人两天口粮和首屋建材、至少两块20×20连通建地、重要资源可达；外围资源更集中。植被生长恢复、矿物残骸有限；动物觅食逃避护域；地形通行/建设/肥力，按需确定性贴图缓存，缩放和总览。
4. 人物与压力：睡床、餐位吃饭、工位工作；房间用途允许混用，环境影响休息生产保鲜舒适。工作检查器解释等待/缺料。天气影响供应链、可干预补救；远征和救助记忆连接关系心情。首日无袭击、明确预警、重大损失后一天恢复窗口。
5. 远征与长期经营：家园与远征双世界同时模拟，共用暂停倍速时钟；选择队员和补给，资源/植物取样/遗迹设备三类任务；返航货物入物流、幂等结算。通信灯塔保留bl_transmitter。全员床位、稳定粮食、冷库备用电力、异星种植、灯塔连续三日达成扎根，继续经营。

## 验收证据要求

- 多种子区域/资源/可达性；采空跨读档切图保留。
- 四向家具、墙角门洞狭窄过道：放置、点击、通行和画面一致。
- 两人抢料、堵工位、停电、取消施工、搬运中读档：守恒、任务可恢复。
- 远征五分钟留守生产，出征者不在家隔空工作，返航奖励只结一次。
- 至少一季、一次可补救危机、一次远征回流的完整游玩。
- 128格、20居民、2000对象：帧/寻路耗时、缓存量、存档大小。小地图测试不得冒充。
- 构建、单元、scenario、perf、boss、UI全绿；本地可视实机另列建造手感、密度、缩放、反馈的观察证据。

## 边界与来源

不加多殖民地、多楼层、气流液体模拟、生育家谱、宗教；保留医疗。禁止API key、3D回退、文字聊天玩法。
